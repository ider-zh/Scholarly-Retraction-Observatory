# 探索结果摘要

本次只对既有 Disruption / NGD 结果进行关联和分层统计，不重算原始图，不改动既有撤稿队列。数值来自冻结结果目录 `20260925/`，完整定义见 [METHODS.md](METHODS.md)。相关系数均为描述性 Spearman，不作因果解释。

## 颠覆度：分类层级和选择条件会改变答案

| 分类 | 主口径有效学科数 | CD 与 OA 标记比例的 ρ | 比例分母限定 2000–2020 的敏感性 ρ |
| --- | ---: | ---: | ---: |
| Concepts L0 | 19 | −0.444 | −0.540 |
| Concepts L1 | 284 | +0.048 | −0.270 |
| Topics Field | 26 | −0.049 | −0.374 |
| Topics Subfield | 248 | −0.211 | −0.346 |

主 CD 为不含发表年、成熟 5 年、有效参考≥10、窗口被引≥5。主比例沿用原报告 2000–2025 发表队列；右列仅改变比例的年代范围，不覆盖主结果。成熟窗口对新论文的选择是重要解释边界。

- Topics 子学科的 11 个预设 CD 口径相关均为负，但强度范围约 −0.457 至 −0.088；方向稳定不等于大小稳定。
- Concepts 子学科在预设口径间约 −0.139 至 +0.158，方向并不稳定。
- Concepts 主学科在11种口径下均为负（−0.739至−0.328）：当前19个主学科中，平均CD较高的学科，其撤稿标记占比排名倾向较低。主口径ρ=−0.444呈中等负向排序关联，但不能外推成单篇论文的保护效应；19个主学科平均CD均为负，较高也可能只是更接近零。
- Topics 主学科主口径接近零（−0.049），11种口径范围−0.299至+0.002；收窄占比发表年代后为−0.374。与子学科负向关系并不相同，说明分类层级与年代均影响观察结果，不支持跨分类体系通用的单一关系。
- 合格主 CD 论文占 OA 全发表队列 22,476,847 / 220,305,891，约 10.203%。不能把这部分论文当作整个学科的无偏代表。

## 学科间关系不等于同学科内的论文对照

PPT“把标记论文放回相近的发表背景”两轴是同一CD组间均值差在分层前后的版本，不是两个独立指标，也不是CD与撤稿占比。现有图中Concepts 217点、Topics 128点：分别214/217、124/128保留差值方向；204/217、118/128满足分层后差值小于分层前差值。调整量（纵轴减横轴）的中位数分别为−0.000770、−0.000653。点呈斜带说明前后差值接近，多数正向差异并未因年份/类型分层而消失；共同层筛选也改变样本，不能把下移全部归因于年份，更不是因果证明。描述性数值绑定与审计见新版`interpretation-audit.json`。

在同学科、同发表年、同文献类型的共同层中，按标记组有效论文数加权；要求共同层标记有效 n≥20，未标记有效 n≥100：

- Topics 子学科：119 / 128 个学科的标记组平均 CD 较高。
- Concepts 子学科：208 / 217 个学科的标记组平均 CD 较高。

这与上一节“学科均值对学科比例”的相关是不同问题，不应相互替代。较高可能只是负值更接近零，不能简称为“撤稿论文更有颠覆性”。未标记也不等于永不撤稿。

RW 58,345 篇匹配论文中，主 CD 合格 14,787 篇；再要求窗口结束严格早于撤稿日期，剩余 5,107 篇。这是不同子集，不是同一批论文的撤稿前后变化。

## 数学距离：没有跨体系一致的“保护”关系

二级学科的数学 NGD 与 OA 标记比例整体相关：Topics 约 +0.104，Concepts 约 −0.061；加入年份×类型间接标准化后，分别约 +0.067、−0.133。正相关才与“离数学越远、比例越高”的预期方向一致，但仍不是保护作用的证据。

高比例主学科内部存在异质性：Concepts 生物学、医学、化学的方向与上述预期一致；工程学的方向相反。部分 Topics 父级子学科很少，相关容易波动，不能只选择支持例。

预先提出的例子并未完全符合直觉：

| Concepts 子学科 | 数学 NGD | 生物学父级内距离组 | OA 标记 n / 发文 N | 标记比例 |
| --- | ---: | --- | ---: | ---: |
| 生物信息学 | 1.166 | 远 | 1,128 / 972,669 | 0.116% |
| 计算生物学 | 1.139 | 中 | 1,179 / 2,080,347 | 0.057% |

“计算”出现在名称里，不保证在标签共现 NGD 中更接近数学。若要研究数学方法本身，需要另建方法或文本变量。
