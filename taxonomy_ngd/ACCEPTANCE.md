# NGD 验收计划

状态：**全量验收已完成，实际证据见 `COMPLETION.md`**。以下保留实现必须满足的证据要求。

## 1. 手工集合 oracle

构造 8 个不同 Work，全集含两个未被下列任何节点标记的 Work：

```text
A (L0) = {1,2,3,4}
B (L0) = {3,4,5,6}
C (L0) = {}
X (L1) = {1,2}, parent={A}
Y (L1) = {3,4}, parent={A,B}
Z (L1) = {}, parent={B}
```

完整矩阵 3×3=9 行；X→A 的计数为 N=8、f_l0=4、f_l1=2、joint=2，NGD=0.5。
X→B 为正边际零交集：NGD=NULL、zero_cooccurrence=true、Jaccard=0。
Y→A、Y→B 都为 0.5、同为父级、并列 rank=1，排除父级排名均为 NULL。
X→C、全部 Z pair 都存在；零边际状态可区分于其他零共现。
重复附带同一标签不改变任何计数；分片顺序和并行度不改变整数结果。

另设 N=100、两边际各 10、joint=1，预期 NGD=1；
N=100、两边际各 20、joint=1，预期 NGD=ln(20)/ln(5)>1，不截断。
相同集合但小于全集的 NGD=0；两集合均为全集时分母为 0，NGD=NULL。
覆盖所有源列表 null/empty、未知年份、所有文献类型、core/xpac 和未撤稿/撤稿状态。

## 2. Topics 多标签跨父级测试

一篇 Work 附带 t1→s1→f1 与 t2→s2→f2；应同时贡献
s1×f1、s1×f2、s2×f1、s2×f2 四个 pair，每个仅一次。
重复 t1 或多个 topics 映射到相同 subfield/field 不得增加该 Work 的计数。
primary_topic 存在但 topics 为空时，不回填；该 Work 仍计入 N。
实体链与 Work 内嵌链冲突、悬空 ID、非法 ID 必须审计并阻断发布。

## 3. Concepts 历史关系测试

零分已附带标签仍计入；只有 L1 标签不能自动补 L0。
多父级使用列表及关系表，不增加矩阵行数；非父级排名排除全部父级。
历史映射切换只允许改变关系标记和相应排名，不应改变 membership、计数或 NGD。
父级 containment 不足 1 产生警告，而不是补标签或删记录。
历史映射的来源标签不能写成“当前快照原生父级”。

## 4. 数值与排名

- 计数非负且不超过 int64；joint 满足上界及集合交集下界 max(0,f_l0+f_l1-N)。
- 所有边际不超过 N；N=0、负数、计数冲突阻断发布。
- 零边际、零共现、零公式分母分别可识别，不产生 NaN/Infinity。
- 数值容差版本化；极小负值保留且警告，明显负值拒绝，不 clamp。
- 原始值 dense_rank，精确并列；四舍五入不改变排名；NULL 无排名。
- 最近非父级可以为多个并列项或无结果，不能凭 ID 伪造唯一最佳项。

## 6. 缓存、交叉分析与压缩

- membership 每个 Work 一行，四组节点列表无重复；保留分类缺失状态与基本元数据。
- 用 membership 缓存独立选定一个测试子总体，重算 N/边际/joint；与原始小图筛选一致。
- 与一对多外部撤稿表关联的示例先约束 Work 身份，不因重复匹配放大计数。
- Parquet 每列/row group 的实际 codec 为 ZSTD，schema 中计数、布尔、列表类型正确。
- metadata、质量与完成清单可 gzip 解压；所有产物大小、SHA256、行数与清单一致。
- 不在 Git 或 public/data 写入大规模数据，不改变既有报告统计。
