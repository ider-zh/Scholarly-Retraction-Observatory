## 决策含义

- 此内核中，Rust 单线程较快；8 线程相近；40 线程 Go 较快。
- Go 40 worker 相对自身单线程约 27.2 倍加速，说明共享只读 CSR 加线程私有 scratch
  在当前设备和此查询集上有效，支持采用 Go 开发第一版并行原型。
- 不是语言的普适排名。构图容器不同，构图时间不纳入引擎排名；未使用 CPU 绑定，
  不是独占主机。重复查询及小工作集偏向热缓存，不能据此承诺真实全图耗时。
- 内存数值只覆盖这个小图，不能当成全快照 RAM 预算。实际图必须独立评估双向 CSR、
  ID 映射、每 worker scratch、解压缓冲和输出队列的峰值总量。
- 真实高入度尾部、全部年龄桶、输入审计、压缩 I/O 与恢复语义仍需生产分层基准。
  这次通过的是合成计数校验，不是完整 `ACCEPTANCE.md` 验收。
