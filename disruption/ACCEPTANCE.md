# Disruption 验收计划

状态：以下保留完整目标的验收标准；**实际全库验收结果见 `COMPLETION.md`**。全库图统计与双口径窗口缓存已完成，不修改撤稿报告数据。计算定义以同目录 `SPEC.md` 为准；实现若与本计划不一致，应先确认定义，而非修改预期值以迎合输出。

## 1. 范围与资产

- 节点层保留当前选定快照的全部 core + xpac Works，不按年份、文献类型、引用数、参考文献数、学科或撤稿状态删除记录；缺失学科必须保留。
- 原始边、规范去重边、节点属性、年度增量统计、窗口结果及完成清单可相互追溯。无法解析 ID、悬空目标、重复边、自身环及时间异常均有审计记录，不静默丢弃原始证据。
- 引用作者自己的其他论文不等于 Work 自身环；第一版不自动排除作者自引。
- 三种角色（focal、reference、future work）均来自约定的全量节点范围。改变 reference/future-work 的类型、学科或 core/xpac 纳入规则属于图统计方法变更，不能声称只筛选最终主表即可实现。
- 窗口结果可以提供一篇一行的宽表，但底层必须保留全部已观察年龄桶，包括 `age_year=0`，不能只保存 3y、5y、10y 累计值。

## 2. 手工小图：计数与窗口端点

### 2.1 输入

测试专用快照截止时间为 `2026-06-26`；这是测试参数，不代表未来生产批次的来源版本。

F 为 2020 年发表的 focal。R 发表于 2018 年，S 发表于 2019 年；有效 reference set 为 `{R, S}`。以下箭头表示引用关系，表中“引用集合”仅列与本用例有关的边。

| Work | 发表年 | 引用集合 | 相对 F 的分类 |
|---|---:|---|---|
| U | 2020 | F | 年龄 0，NF |
| V | 2021 | F | 年龄 1，NF |
| W | 2022 | F、R、S | 年龄 2，NB |
| X | 2023 | R、S | 年龄 3，NR |
| Y | 2024 | F | 年龄 4，NF |
| Z | 2025 | F、R | 年龄 5，NB |
| T | 2026 | S | 年龄 6，NR；截至快照已观察到 |

令 W 的原始引用列表重复包含 F 和 R，X 重复包含 S。必须仍然分别只贡献一个 NB、一个 NR，而不是按边数、共同参考文献数或连接路径数累计。

为检查 reference set，令 F 的原始引用列表为 `[R, R, S, A, B, D, Q, F]`：A 为 2020 年，B 为 2021 年，D 缺发表年，Q 是格式合法但节点表中不存在的 ID。预期：

- 原始条目数 8；不同目标 ID 数 7；有效参考文献数 2。
- 重复条目 1，同年目标 1，未来年份目标 1，目标年份缺失 1，悬空目标 1，自身环 1，均有审计证据。
- 同年目标 A 在两套观察窗口中都不能进入 reference set；切换观察窗口不改变 reference set。
- 非法 ID、空值引用条目另设用例，验证其审计分类，不能混成合法悬空节点。

### 2.2 标准累计结果

| 口径 | 窗口 | 纳入年龄 | NF | NB | NR | 直接引用数 | 局部相关 Work 数 | CD | no-NR |
|---|---|---|---:|---:|---:|---:|---:|---:|---:|
| 不含发表年 | 3y | 1…3 | 1 | 1 | 1 | 2 | 3 | 0 | 0 |
| 含发表年 | 3y | 0…2 | 2 | 1 | 0 | 3 | 3 | 1/3 | 1/3 |
| 不含发表年 | 5y | 1…5 | 2 | 2 | 1 | 4 | 5 | 0 | 0 |
| 含发表年 | 5y | 0…4 | 3 | 1 | 1 | 4 | 5 | 2/5 | 1/2 |
| 不含发表年 | lifetime | 1…已观察年龄 | 2 | 2 | 2 | 4 | 6 | 0 | 0 |
| 含发表年 | lifetime | 0…已观察年龄 | 3 | 2 | 2 | 5 | 7 | 1/7 | 1/5 |

其中 `CD=(NF−NB)/(NF+NB+NR)`，`no-NR=(NF−NB)/(NF+NB)`；表中分数是用于比较的精确分数，存储数值比较使用明确的浮点容差。

- 两套 10y 的已观察计数应分别与本用例对应的 lifetime 相同，但 10y 都未成熟，标准完整窗口分数必须为 NULL。
- 3y、5y 在本用例均成熟；不含发表年 5y 计划结束日为 `2025-12-31`，含发表年 5y 为 `2024-12-31`。
- 不含发表年 10y 计划结束日为 `2030-12-31`，含发表年 10y 为 `2029-12-31`。不能仅用 `snapshot_year−publication_year` 决定成熟度。
- 从年度桶另算 4y、7y、年龄 2…5，验证无需扫描边表即可获得累计结果；年龄 2…5 的预期为 NF=1、NB=2、NR=1。
- 同年 U 只能称为同年引用关联，不能因其进入年龄 0 桶便声称已知严格先后顺序。
- lifetime 始终表示截至快照的累计观察，不存在“最终一生已完整观察”的成熟承诺；`is_mature` 为 NULL，使用 `snapshot_limited` 表达限制，不能默认按未成熟有限窗口屏蔽有定义的 lifetime 分数。

### 2.3 全图入度不等于后续 lifetime 引用数

另加 P（2019 年）引用 F、J（年份未知）引用 F。规范图排除 Work 自身环、去重后，F 的 `graph_indegree_all` 为 7；发表次年起的 lifetime 直接引用数仍为 4，含发表年口径为 5。P 和 J 必须分别进入逆序、未知年份审计，不能被分配为零年龄或删除节点。

独立设置 OpenAlex 原始 `cited_by_count` 与 7 不同，检查 delta 按约定方向记录，并产生来源差异警告；不可为了消除差异覆盖来源原值。

## 3. 零、缺失、未成熟与退化状态

| 用例 | 必须观察到的行为 |
|---|---|
| 无有效参考文献，但有后续直接引用 | NF 可大于 0，NB=NR=0；raw 公式可为 1，但解释性标准分数为 NULL，保留 `no_references` |
| NF=NB=0、NR>0 | CD raw 为 0；no-NR 为 NULL；“无直接后续引用”不等于“空局部邻域” |
| NF=NB=NR=0 | 两式分母均为零，分数为 NULL，而不是 0；已完成统计的计数可为 0 |
| 2024 年论文、2026-06-26 快照 | 两套 3y、5y、10y 均未成熟；已观察计数保留，observed raw score 按分母计算，完整窗口分数为 NULL |
| focal 年份未知或非法 | 节点、可得原始属性和无时间限制图信息保留；`reference_count_valid` 为 NULL，不可构造有效年龄桶或成熟度，时间相关结果为未知而非零 |
| 未来日期、日期与年份冲突 | 产生独立质量标记，并按版本化日期优先级规则处理，不擅自修补日期 |
| 多种问题并存 | `no_references`、未成熟、内部不一致等独立 flags 可以同时为真，主状态不能覆盖其他问题 |
| 无 primary topic | 所有图计算照常保留；分类字段为 NULL，不伪造学科，也不静默排除出总记录数 |

参考文献、引用阈值便利 flags 必须从保留的原始数值派生；不可将阈值不满足误写成图计算失败。质量字段不得把“未检查”“已检查失败”“已检查通过”混为一类。

## 4. 稀疏存储与任务完成状态

必须分别构造并验证以下状态：

1. focal 计算完成、某桶处于可观察范围、没有相关 Work：稀疏表可缺行，查询视图补零。
2. focal 或分区尚未完成：即使无桶记录，也只能表示未计算，不得补零。
3. 超出快照的未来桶：不可观察，不补零。
4. 当前尚未结束的自然年：已有计数可返回，但必须带部分年度/观察截止信息，不能标成完整年度。
5. 进程中断产生部分文件：没有完整提交标识时不得被正常结果视图读取为完整分区。
6. 重试或续算：不能重复累计，完成标识、统计行和所属版本必须一致。

缺行补零必须同时检查完成清单和观察范围；仅凭 Parquet 文件存在不够。

## 5. 一致性检查与发布策略

**用户已决定：内部计数一致性问题仅警告，不作为发布阻断条件。** 测试应故意注入一个直接引用数不等于 NF+NB 的窗口，确认：

- 独立计算的直接引用数与 NF/NB 都保留，记录差值及 `citation_count_consistent=false`。
- 行级标记、批次警告汇总和发布元数据能发现该问题，不将其描述为“检查通过”。
- 结果仍可发布，不自动覆盖某个计数以凑齐恒等式，也不删除该论文。
- 同理检查局部相关 Work 数与 NF+NB+NR；差异须显式报告。
- OpenAlex 原始引用数与规范图入度的差异独立记录，不与上述同口径内部恒等式混淆。

此例外不意味着任何损坏都允许发布。不可读取的文件、主键冲突、计数为负、版本混写、错误 schema、文件校验失败或未完成分区冒充完成等结构/完整性错误，应阻止对应产物进入正常结果集，提供失败诊断。警告策略不能被用于掩盖未执行的计算。

## 6. 可复用性与撤稿研究接入

- 同一快照、相同图规则下，SQL/dataframe 可以修改 focal 的引用阈值、参考文献阈值、类型、年代、学科及年度窗口，不重新扫描全图。
- 宽表的 3y、5y、10y、lifetime 必须能由年度长表再生，并区分两套窗口口径。
- 第一版只承诺 CD、no-NR 两式及其筛选/归一化；共同引用至少两篇、边权、自引排除等扩展不能伪称 NF/NB/NR 已足够支持。
- 与撤稿表通过规范 Work ID 关联时，只筛选 focal，保留完整引用图下的统计；不能将后续引用论文或 reference set 顺带裁成撤稿子图。
- 联结必须检查撤稿记录一对多导致的重复行；多条撤稿来源记录不得重复计算同一 Work 的统计。
- field/year normalization 单独版本化，记录 cohort、类型、成熟度、缺学科与 eligibility 规则及窗口口径。不能把撤稿子集内的排名冒称为全领域发文中的百分位。

## 7. 来源、版本与可复现

- 每批结果能定位实际快照 manifest、输入文件清单/校验、计算与 schema 版本、代码版本、规则配置、生成时间及完成清单。
- 来源日期必须来自已验证证据，不能将下载时间、生成时间或示例日期冒充快照日期。
- 已存在的下载前 provenance 缺口如实保留，不能补写虚构的下载前 manifest 或传输日志。
- 小图重复运行、分区顺序变化或并行度变化，整数计数不变；浮点派生结果满足指定容差。
- 新快照或方法变更产生新版本，不覆盖旧定义而丢失追溯链。跨快照增量维护不属于第一版验收承诺。

## 8. 后续资源基准与启动条件

本节为执行约束。工具与压缩基准已运行，完整图上的 32 个压力样本也已完成；
证据见 `benchmarks/` 与 `FULL_RUN.md`。全库验收的独立证据见 `COMPLETION.md`，不能把样本验收当作全库验收。

- 先运行覆盖普通节点和高连接节点的分层基准，再估计全量成本，尤其是 NR 邻域去重的成本；不能只用低度数论文外推。
- 精确去重，不允许静默采样、近似计数、截断高入度节点或减少论文覆盖以满足预算。
- 初始上限：40 个逻辑 CPU、384 GiB RAM；临时 spill 使用 `/mnt/hg02`，不用根目录 `/tmp` 承担大规模数据。
- 新增磁盘最多 4 TB，同时至少保留 1 TB 可用空间，以更严格条件为准；执行前检测现有占用并明确容量单位。
- 预计超预算或运行中触及保护阈值时暂停并报告，不擅自提高预算或更换统计定义。
- 记录实测 wall time、CPU、峰值内存、临时磁盘峰值、输入/输出规模、失败/重试及覆盖情况；不能将资源上限写成性能保证。
