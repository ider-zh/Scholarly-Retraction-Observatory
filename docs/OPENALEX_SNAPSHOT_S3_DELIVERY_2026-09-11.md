## 全库计算

- 引用扫描：2,446 个 Works 分片，**43,094 个目标、878,951 条不同入边**。扫描引用方包含 core 与 expansion，目标限定已筛选的 core article C。
- 引用扫描使用 6 worker × 8 线程，每 worker 上限 32 GB，耗时 **452.3 秒**。补充分母同配置，耗时 **273.4 秒**。内存/线程为资源配额，不是持续使用量。
- 两轮均使用内容版本化的分片检查点和输出 SHA-256；完整 Work ID 唯一性由前置全实体审计保证。中间匹配记录、引用边及补充 Parquet 只保存在外部磁盘。

## 引用结果核对

快照对齐时排除 233 个较晚 RW 事件目标，留下 42,861 个目标；其中两个目标的首次事件日期冲突，保留为事件日期不可用。

| 时序类别 | 观测边数 |
| --- | ---: |
| 明确之前 | 580,835 |
| 明确之后 | 283,113 |
| 重叠 / 同日 | 10,556 |
| 日期不可用 | 76 |
| 合计 | 874,580 |

报告日口径下，时间可判定边中的撤稿后比例为 `283113 / 863948`，约 **32.77%**。这不是错误传播率或因果效应；双方日期扩大到整年的敏感性另列，引用日期只是发表时间代理。

共同五年随访队列包含 **12,923 个目标**；1/3/5 年均值分别为 2.878、6.486、9.005 条观测边，中位数分别为 1、2、3。各窗的分子总边数分别为 37,197、83,818、116,372。此结果条件于完整五年随访，不能直接代表近期撤稿作品。

全部目标的 rebuilt edge count 与静态引用计数在 719 个目标上不同，绝对差合计 3,364；静态总计 875,587，重建边总计 878,951。差异保留为数据质量核对，不强行调整入边或拿静态计数作事件比例分母。
