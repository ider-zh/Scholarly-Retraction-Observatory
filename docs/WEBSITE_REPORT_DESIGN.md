# Website Report Design — 撤稿研究网站报告设计

版本：1.0 · 日期：2026-09-10 · 状态：设计规格；2026-09-11 起分阶段实现

实现进度：已加入独立 v3 页面、分章校验加载、有限切片、聚合导出和离线统计流水线。后续实现加入版本化原因族、当前出版商归属、incoming 引用事件时间及固定日历随访；具体已计算能力以生成的 manifest 为准，不能把本设计目录当作全部完成声明。每章默认展示最多四张不同分析主图，更多切片折叠或通过下拉框直达。参见[运行说明](OPENALEX_SNAPSHOT_RUNBOOK.md)。

关联规范：[OpenAlex Snapshot Analysis Spec v2](OPENALEX_SNAPSHOT_ANALYSIS_SPEC.md)；当前线上统计口径：[RESEARCH.md](RESEARCH.md)。

本设计只规划下一阶段的 React 网站报告，不表示已下载、验证或分析 OpenAlex 全量快照。当前 RW 报告继续保留。文中的公式、示例和页面草图不是新的研究结果。

## 1. 产品目标：从统计看板变成可阅读的研究报告

网站应同时支持两种使用方式：第一次访问的读者沿着研究问题阅读，研究型用户直接进入某个维度筛选、比较并检查计算口径。默认界面是有叙事顺序的报告，不是几十张图的无差别拼接。

报告围绕七个问题展开：

1. 我们实际观察到了什么，两个数据库分别覆盖什么？
2. 撤稿何时发生，与原论文何时发表有什么区别？
3. 哪些学科、主体和出版渠道关联更多，控制发文规模后是否仍如此？
4. 原因如何分布，哪些原因与哪些研究主题共同出现？
5. 这些现象分散还是集中，合作结构如何影响计数？
6. 论文撤稿后，在引文网络中还会持续出现多久？
7. 哪些结果稳健，哪些仍受覆盖、时间窗、身份和分类问题限制？

每章默认提供一个主结论区域、一张主图和两至三张补充图。高级视图折叠，不能为了图表数量牺牲可读性。主结论必须由已通过质量门槛的数据生成；没有结果时说明缺少的条件，而不是展示预先写好的结论。

### 本次设计边界

本次不修改 `src/`、pipeline、公开统计 JSON 或发布工作流。后续实现按能力分阶段启用。禁止用目前的约 1,000 次 DOI 调试查询生成新报告；禁止用展示样本填充全量图表；禁止把待计算的结果显示为 0。

## 2. 信息架构与阅读顺序

保留“当前 RW 报告”，另设“快照联合研究报告”。两者有独立 release ID、总体和日期，不以新模块覆盖旧页面数值。

| 章节 / 规划路由 | 读者的问题 | 主内容 |
|---|---|---|
| 研究概览 `/snapshot/overview` | 这份报告研究什么，主要观察是什么？ | 来源范围、质量状态、3–4 条有证据的发现、阅读路径 |
| 时间与观察期 `/snapshot/time` | 撤稿增加了，还是我们看到得更多？ | 双时间轴、发表–撤稿矩阵、队列比例、时滞 |
| 学科与主题 `/snapshot/fields` | 总量和发文规模标准化后有何不同？ | 分层下钻、时间热力图、规模–比例对照、排序变化 |
| 撤稿原因 `/snapshot/reasons` | 记录的原因有哪些，是否共同出现？ | 多标签分布、原因×学科、组合、时滞对照 |
| 地理与合作 `/snapshot/geography` | 国家关联与国际合作如何统计？ | 国家关联、完整性分组、国家合作矩阵 |
| 机构与作者 `/snapshot/entities` | 撤稿关联分布和集中程度如何？ | 机构规模、作者重复关联、Lorenz、去重覆盖 |
| 期刊与出版 `/snapshot/publishing` | 哪些出版渠道有不同模式？ | 规模–比例、撤稿月份、出版群体时滞 |
| 引用与持续传播 `/snapshot/citations` | 撤稿后的引用是否继续出现？ | 引用分布、事件时间、时序可判定性、固定观察窗 |
| 数据与方法 `/snapshot/data-methods` | 这些结论可信到什么程度？ | 匹配矩阵、角色排除、缺失情况、公式、来源与复现 |

以上是逻辑路由；实现可采用 hash 路由以适应静态部署，不强制新增路由依赖。现有入口和已有书签应保留或提供明确映射。

桌面左侧目录按章节定位，移动端使用可折叠目录。作者、期刊和学科明细优先使用页面内侧栏或子视图，避免无限新增一级菜单。样本观察放在解释侧栏，明确“仅供理解字段，不代表总体”。

研究问题与范围说明（两至三句）

[OA 标记记录 A0] [筛选后候选 A1] [RW 原论文 B] [高置信匹配 C]
 每张卡解释统计单位；卡片之间不能直接相加。

[当前可发布的发现：数值 + 对照 + 适用范围 + 查看证据]

移动端顺序为：问题 → 关键观察 → 图表 → 解释 → 数据与方法。关键限制不能只放在悬浮提示里。

## 4. 共用 ChartCard 规范

每个主要图表必须具备以下结构，不接受“只有标题和图”的交付：

| 元素 | 要求 |
|---|---|
| 研究问题 | 用问题句说明这张图要帮助判断什么 |
| 指标标题 | 写明数量 / 关联覆盖 / 关联份额 / 队列比例 / 时滞，不能只写“占比” |
| 范围条 | population、corpus、作品类型、日期或观察窗、分类与计数方式 |
| 可视编码 | 轴名、单位、图例、颜色含义、缺失与零的区别 |
| 数据观察 | 至少一句带实际数值、比较对象和样本量的描述 |
| 数据解读 | 说明比较揭示的是规模、构成、时间分布还是覆盖差异 |
| 解释边界 | 最相关的一至两条限制，不能只复制“仅供参考” |
| 证据入口 | 可访问数据表、公式、缺失统计和方法版本 |
| 联动 | 点击后发生什么、哪些筛选会影响这张图，应可预期 |
| 导出 | 仅导出图中聚合单元和对应元数据，不导出原始全库 |

Tooltip 至少包含完整名称、未缩略数值、单位、n/N、总体、年份、计数规则、缺失/小基数标记。长机构名称可以在轴上截断，但 tooltip、数据表和导出必须保留全名。

`IQR` 是 P25–P75 的分布区间，不是中位数的置信区间。参考线要说明是全体、同学科、同年份还是其他基准。任何排序必须声明筛选条件、排序指标和最低样本要求。

## 5. 图表目录：时间与观察期

以下 ID 同时用于数据契约、前端 registry、解释文本和测试。A0/A1/B/C/D 的定义以分析 spec 为准。

### T1 — 两种年份的并列时间趋势

- 问题：撤稿处理发生年与原论文发表年分别呈现什么分布？
- 默认总体：B；两个对齐的小面板使用同一批 RW 原论文，但缺失日期分别排除。发表年横轴和首次有效撤稿年横轴分别标明；纵轴为原论文数。
- OA 模式只允许 A1 的发表年面板，不生成不存在的 OA 撤稿年。
- 编码：柱形 + 可选后向三年均值；未完整年度用纹理/标记，不能只变浅色。补零须有该年份纳入统计且扫描完整的证据。
- 联动：点击某年查看其学科/原因构成，只影响声明支持该切片的图。
- 解读重点：峰值位置、完整年度变化、两个时钟的区别。不得把某撤稿年数量除以同年发文量当作撤稿率。

### T2 — 发表年 × 撤稿年矩阵

- 总体：B 或具有有效日期的 C；单元格为唯一原论文数。
- X：发表年份；Y：首次记录撤稿年份；颜色：数量，可选明确标注的 `log1p(count)`。
- 对角线表示较短时滞；早于发表年的格子属于日期异常，单独审计，不作为正常热区。
- 联动：点击格子查看该批论文的原因、学科构成及计数范围。
- 解读重点：撤稿年份峰值来自哪些发表年代。沿某一撤稿年形成的集中带只能描述批次集中，不能凭形状认定为某次调查或论文工厂事件。

### T3 — 发表队列的已记录撤稿比例

- 总体：A1/D，或另名的 C_D/D；X 为发表年份，Y 为每万篇的观测比例；tooltip 必须有 n/N。
- OA 仅提供截至其快照的 flag-based 比例；RW 定年模式可提供满足完整随访的固定年限比例。
- 不满足 1/3/5 年观察窗的队列显示“观察期不足”，不是 0。两个定义不能共用同一图例名称。
- 可选点图/区间图；模型区间默认关闭，不把区间解释为数据库漏收误差。
- 解读重点：最近发表队列的低值可能只是观察期短。不得自动输出“科研诚信改善”。

### T4 — 撤稿时滞的 ECDF 与分位数

- 总体：B 的有效日期原论文，或另行明确的 C；X 为发表至撤稿年数；Y 为有效样本中时滞不超过 X 的累计比例。
- 主图采用 ECDF，补充 P25/P50/P75/P90；按学科/原因分组时最多同时显示四条曲线，并展示各组 n。
- 点击某个年限可以得到该年限内的已撤稿样本比例。使用半开区间的直方图作为可切换视图，替代用环图判断连续分布。
- 解读重点：“已有撤稿记录的样本中，有多少在该时间内被撤稿”，不是普通论文未来的累计撤稿风险。

## 6. 图表目录：学科与主题

### F1 — 学科分层下钻

- RW 模式：官方一级前缀 → 完整二级 Subject；OA/联合模式：Domain → Field → Subfield → Topic。
- 默认横向条形图，显示层级面包屑、关联数、覆盖数和未知分类。支持回到父级，保持独立的 taxonomy ID。
- OA 默认 primary-topic；any-topic 是独立开关，在父层先按论文去重。分类未知不挤占 Top-N 已知学科。
- 可选 icicle/treemap 仅在可加总的主 Topic 模式启用；不可把多标签全计数放入暗示总量守恒的面积树。
- 解读重点：哪个层次的研究方向占据较多记录，以及下钻前后的统计单位有没有改变。Concept 仅作标为 legacy 的附录，不放入这条层级路径。

### F2 — 学科 × 年份热力图

- 总体：A1 的发表年，B 的事件年，或 C 的明确日期模式；X 年份，Y 学科，颜色为全计数或具备 D 的队列比例。
- 数量和比例使用不同色标/单位；事件年模式禁用队列比例按钮。未知/未计算格子用纹理而不是 0 色。
- 默认每屏最多 20 个学科、固定年份范围；排序规则显示在图上。颜色可使用全矩阵尺度或行内标准化，但两者必须独立命名，不能无提示切换。
- 解读重点：集中在哪些时期/领域，以及“颜色更深”是数值更大还是相对于该行自身历史更高。

### F3 — 发文规模与观测比例的对照散点

- 总体：A1/D 或 C_D/D；每点为一个同层级学科。
- X：符合口径的全部发表数 N，可用 log 轴；Y：每万篇观测比例；tooltip：n、N、年份、作品类型和分类规则。
- 参考线为同范围合并分子/分母的总体比例，不是组比例的算术平均。点大小默认一致，避免第三个冗余尺度。
- 联动：选择最多四个学科进入并排对比；n/N 不满足排名门槛的点仍可查看，但不生成“最高”结论。
- 解读重点：数量较多与比例较高是否是同一批领域；未经领域和时代控制的比例不称为固有风险。

### F4 — 数量排名与比例排名的变化

- 总体：同一发布队列中同时满足条件的学科；用 slopegraph 或并列排名表比较 count rank 与 cohort-proportion rank。
- 必须以相同的完整可排名实体集计算排名，再截取展示；并列名次用稳定规则，不用 Top-N 子集重新排名。
- 联动：点击变化较大的学科，回到 F3 和该学科时间分布。
- 解读重点：规模标准化改变了哪些表面排序。不可把比例排名包装成科研诚信排名。

## 7. 图表目录：原因与研究主题

### R1 — 原因标签记录比例

- 总体：B；横向条形图；X 为记录该原因的原论文数或 `paper_coverage_pct`，Y 为原始原因/自定义原因族。
- 默认分母为当前范围所有 B 原论文，缺失原因单独显示。标签可以多选，因此各原因比例合计可能超过 100%。
- 切换原因族时保留原标签映射和版本；调查/通知描述不伪装成已证实原因。
- 解读重点：哪些标签被记录得更多，而不是哪些不端行为在现实中更普遍。禁止默认用饼图或 100% 堆叠图表示重叠的论文覆盖。

### R2 — 原因 × 学科 / Topic 热力图

- 总体：C；默认 X 为原因族，Y 为 OA Field；下钻到已预计算的 Subfield/Topic。
- 单元格默认 `n(记录该原因且属于该学科) / N(该学科的全部匹配原论文)`，包括原因缺失论文在该学科分母内，并单列缺失率。
- 可切换为数量，但不能把横向/纵向条件概率互换而保持同一标题。每格 tooltip 同时给 n/N、匹配覆盖和缺失情况。
- 联动：选择一个格子打开该组合的时间、时滞和来源解释；组合未预计算则说明“不支持此切片”。
- 解读重点：这个学科中更常记录的原因是什么；部分匹配及原因漏记会改变表面构成。这是联合报告的重点主图。

### R3 — 原因共现组合 UpSet

- 总体：B 或明确的 C；以原因族构造互斥的完整组合，每篇论文在组合模式中只贡献一次。
- 交集点阵说明组合，柱高为唯一原论文数；默认展示前 10 个组合，剩余组合汇总为 Other。缺失原因独立显示。
- 另一种 pairwise 共现矩阵必须使用不同 chart mode；两两共现不等于完整组合，也不能被相加当论文总数。
- 解读重点：多标签原因如何共同出现，不能把标签共现解释为因果链或事件发生先后。

### R4 — 不同原因对应的撤稿时滞

- 总体：原因可用且日期有效的 B/C；每行一个原因族，中位数点 + P25–P75 区间，标注 n。
- 至少 20 个有效原论文才显示比较区间；较小组保留样本量和“样本不足”说明，不拼出精确排序。
- 多原因论文可出现在多个组，组并不独立。默认每组对唯一原论文计算未加权分位数，不跟随其他页面的 fractional 开关改变。
- 解读重点：记录的撤稿时滞差异，不声称这是发现违规所需的时间，也不声称每个原因都在首次撤稿日已被确认。

## 8. 图表目录：地理与合作

### G1 — 国家关联分布与规模对照

- 总体：A1 或 C；默认 `institution_country`，同一论文每个国家最多计一次。RW 原始 Country 作为独立来源视图。
- 默认 Top-15 横向条形图 + 完整可用聚合表；允许切换 full/fractional、论文覆盖比例、关联份额、具备分母的队列比例。
- 每次切换同时更新标题、分母说明和导出列名。未知国家显示在独立覆盖卡片，不作为国家排名的一项。
- 可选地图只作辅助，明确无数据与零值；绝对量地图不替代精确可读的条形图，也不靠地图面积表达数量。
- 解读重点：国家是论文署名关联，不是作者国籍或国家责任。Full-count 分组和可能超过论文总数。

### G2 — 合作规模与数据完整性

- 总体：A1/D 或 C_D/D；分组必须保留“多国已观察”“单国且未发现缺失”“单国但不完整”“国家未知/完整性不明”。
- 主图为各组原论文数与覆盖比例的条形图；完成分母验证后提供分组队列比例点图，不能把比例与数量放在无解释的双 Y 轴中。
- 多国记录再分为观察到两国、三国及以上；这些是已观察到的下界。
- 解读重点：合作组之间的差异是否伴随缺失差异；单国不完整组不能用来代表纯国内合作。

### G3 — 国家合作矩阵

- 总体：具有至少两个已知国家的 A1 或 C；每个国家对在同一论文中最多贡献 1。
- X/Y 国家；上三角显示共同关联论文数，主对角线不适用；tooltip 给共同论文数、国家口径、覆盖完整性。
- 默认全计数；可选 pair-fractional 模式每篇论文按 `1 / C(k,2)` 分给观察到的国家对，必须单独标注，不与国家等分权重混用。
- 解读重点：可观察的共同署名结构；不是不端协作证据。默认不采用难以阅读的毛线团网络图。

## 9. 图表目录：机构、作者和集中程度

### E1 — 机构关联数量与发文规模

- 总体：A1 或 C；默认直接机构 ID 的 Top-15 lollipop/bar chart，tooltip 显示符合范围的 N、比例可用性及完整性。
- 独立开关切换直接机构与明确的母机构聚合，不能同时重复计算医院及其上级大学。
- 旁边固定显示“机构未知”“部分机构未解析”的覆盖卡；真实机构内含 unknown 等字样时不能靠关键词删除。
- 点击机构进入已发布聚合详情：发表年、学科、原因/时滞可用性。只展示实际预计算的维度。
- 解读重点：大机构的较大计数是否伴随不同发文规模；不得生成“最差机构”标题。

### E2 — 作者重复关联分布

- 总体：A1 或 C 中有效 OA 作者 ID；X 为 1、2、3–5、6–10、>10 篇的分组，Y 为作者数。
- 同一作者/论文去重；NULL/删除占位作者不作为真实作者计数，未知覆盖单列。
- 默认展示分布而非姓名排行榜；姓名明细限于有充分来源链接的少量展示项，并提示作者消歧错误和责任不等同。
- 解读重点：单次关联和多次关联的作者分布；不能把关联多篇直接命名为“惯犯”。

### E3 — 关联分布的 Lorenz 曲线

- 可选作者、机构、期刊；X 为按关联量升序排列的实体累计比例，Y 为累计关联份额；同时显示等分参考线和 Gini。
- population of entities 必须说明仅含至少一篇撤稿关联的实体，还是包括全部合格发表实体的零值。两种曲线不可无提示替换。
- 离线使用完整实体分布计算，公开只输出有误差控制的曲线采样点、指标和方法；不能拿 Top-15 计算 Gini。
- 解读重点：关联计数是否集中，以及换成分数计数后集中程度如何变化。未知占位值不作为一个超级实体。

### E4 — Top-k 实体的唯一论文覆盖

- X 为按固定指标排序的前 k 个实体；Y 为它们关联论文集合的去重并集 / 当前总体论文数。
- 这是 unique-paper coverage，不是把各作者或机构的计数相加。Top 1/5/10% 的 k、并列规则、实体总数写入 metadata。
- 与 E3 提供并排解释，而不是混用两个“贡献占比”。可以比较 full-count 排序与 fractional 排序，但各自明确。
- 解读重点：少量实体覆盖了多少不同论文；重叠署名会让“关联集中”与“论文集中”产生不同结果。

## 10. 图表目录：期刊与出版生态

### P1 — 期刊发文规模与队列比例

- 总体：A1/D 或 C_D/D 的 journal-source 子集；X 为 primary source 的合格发文量 N，Y 为每万篇观测比例。
- 只使用主发表来源，不把同一论文的多个存储库 location 当成不同期刊。非期刊和来源缺失单列。
- 支持按当前 publisher/imprint 筛选，tooltip 显示当前归属口径；不自动推断历史所有权。
- 解读重点：数量榜与比例图是否不同；不输出出版商诚信评分。

### P2 — 期刊 / 出版商撤稿月份热力图

- 总体：有 RW 事件日期的 C，或独立使用 RW 原始出版字符串的 B；X 为月份，Y 为来源/出版商。
- 色深为当月首次有效撤稿的原论文数；选择一行显示月度柱状序列与预注册的 burst 提示。
- 没有可靠日期/月份覆盖时显示不可用，不用 OA 更新时间代替。特定事件注释需有来源链接、实际事件日期和人工复核状态。
- 解读重点：撤稿处理集中于哪些时间窗；峰值可能包含批量处理，但图形本身不能证明原因。

### P3 — 出版群体的时滞对照

- 总体：有可靠日期及来源的 C；X 为年数，Y 为期刊或出版群体；中位数点 + IQR + n。
- 支持相同发表年代/主要学科的已预计算切片；不把无控制的总体差异包装为编辑效率排名。
- 显示 publisher attribution 是快照当前归属还是有历史依据的归属。
- 解读重点：观察到的滞后分布如何不同，是否可能受论文年代、学科构成及批量事件影响。

## 11. 图表目录：引用影响与撤稿后持续引用

### C1 — 撤稿论文的引用分布

- 总体：A1 或 C；X 为引用数，Y 为 ECDF；零引用单独标注，可切换 log1p X 轴。保留零与缺失的区别。
- 默认只展示撤稿样本分布；未撤稿对照只有在明确相同发表年代、作品类型和学科切片后才可启用。
- 显示中位数、P90、零引用比例和数据可用性；均值可作为补充，不能独占摘要。
- 解读重点：长尾与少量高引用论文，不能把累计引用数当作论文质量或未经年代控制的影响差异。

### C2 — 以撤稿日为中心的引用时间曲线

- 总体：具备可靠 RW 撤稿日期及 incoming citation edges 的 C；X 为相对撤稿时间，0 为事件边界。
- 默认每个相对年度展示“每个有完整该年度观察窗的目标原论文的已观察引用数”，同时显示 eligible-target n。不同 bin 的 n 不一致时不能隐藏。
- 可选共同完整窗口队列作前后比较，说明这一筛选偏向观察期充足的论文。事件当日/区间重叠引用进入模糊组，不硬分两侧。
- 解读重点：引用在事件前后如何持续；不是撤稿造成引用变化的因果估计。不能用目标论文自身的 references 代替 incoming citations。

### C3 — 引用时序的可判定性与撤稿后比例

- 同一目标集合的引用边分为：明确之前、明确之后、时序模糊、日期不可用。用可加总的条形构成图显示四组。
- 主指标为 `after / (before + after)`，明确称为“时间可判定的观测引用边中的撤稿后比例”；同时给模糊和缺失覆盖。
- 按学科比较时展示各组全部四类覆盖，避免把“日期更完整”误判为传播模式不同。
- 解读重点：持续引用比例与可判定性必须一起读。引用可能是在批评、复核或说明撤稿，不能称为“错误继续传播率”。

### C4 — 撤稿后 1 / 3 / 5 年的引用持续情况

- 总体：对应观察窗完整的 C；点图/区间分布展示每目标论文的已观察引用中位数、均值及至少一次引用的论文比例，并标注 n。
- 比较 1/3/5 年曲线时，默认使用共同满足最长观察窗的队列。选择各窗口自己的合格队列时分面显示，不能当成同一组的增长曲线。
- 没有引用边与没有完成扫描不同；前者可为观测零，后者必须是 unavailable。
- 解读重点：在明确观察窗内，引用是否仍可观察到。未达到五年随访的论文不能填入五年统计。

## 12. 图表目录：数据质量、核对与方法

### Q1 — RW × OA 核对矩阵

- 展示 RW 高置信匹配且 OA flag=true、匹配且 false、匹配但 flag 缺失、RW 未匹配/歧义，以及 OA flag=true 但未与 RW 原论文匹配等状态。
- 默认矩阵/分组条形图；可选分支流程图，但边必须守恒且每条路径标明统计单位。RW 总数与 OA 总数存在重叠，不能直接加成一个总数。
- 同时给全 RW 原论文匹配覆盖与“仅有 DOI 的原论文”条件匹配率。
- 解读重点：识别、角色分类、日期与传播状态为何导致差异。两源不是独立检验，不显示未经独立真值审计的 accuracy/precision/recall。

### Q2 — 缺失与覆盖热力图

- X 为 DOI、日期、学科、机构、国家、有效作者、引用日期等质量维度；Y 为来源/发表年代/已验证分层切片。
- 每格显示 usable n / eligible N；分母明示。不同数据源的“原始机构字符串存在”与“标准化机构解析成功”是不同指标，不能放进一个无区别的同名列。
- 多缺失状态可能重叠；堆叠图只用于互斥状态，其他情况用矩阵。
- 解读重点：结果最容易在哪些年代或维度受到选择偏差影响；匹配覆盖不是身份识别准确率。

### Q3 — 从标记记录到分析队列的排除流程

- 从 A0 开始显示 corpus 筛选、作品类型、已知通知、角色冲突/待审、其他资格限制，最终到 A1。
- 每一步按固定优先顺序构造互斥排除集合；同时保留非互斥质量标签作为另一张表。不能把重叠排除数量直接相减。
- 使用 waterfall 或步骤条形图，注明每一步的基数和保留数；旁边链接 D 的同口径构造说明。
- 解读重点：为什么 OpenAlex flag 总数不是原论文撤稿总数。历史 API 核查仅做有日期的对照，不作为当前图表值。

本目录共定义 **29 个独立分析图表 ID**；概览复用其中经过验证的图表，不另建一套计算。可选地图、层级面积图、历史 Concepts、网络等属于扩展视图，不是第一版必须实现的数量目标。

## 13. 数据解读规范：让图表产生可检查的认识

### 13.1 五层解释

每张主图的解释依次回答：

**观察到了什么？** 用数值、分母、时间范围和明确对照描述结果，而不只是“某组最高”。优先解释数量与比例是否不同、分布是否长尾、集中度如何、哪个阶段发生变化、覆盖是否不均衡。

**为什么这个对照有意义？** 说明它区分了发文规模与队列比例、发表年与事件年、关联次数与去重论文、累计引用与固定窗引用等不同概念。

**有哪些可能的解释？** 只有有依据时才描述可能机制；作为待检验假设单独显示。外部事件必须引用可靠来源，不能因为出现峰值就自动生成“集中清理论文工厂”。

**哪些结论不能推出？** 根据当前图给具体限制，例如“机构规模已校正，但学科构成未校正”，优于泛泛的“相关不等于因果”。

**怎样进一步核查？** 只链接本站已存在的支持图、质量矩阵、方法或来源，不承诺浏览器拥有未发布的原始数据。

### 13.2 解释文本的数据契约

观察文本默认在离线 pipeline 用确定性模板生成；支持的筛选切片必须同时生成对应观察数据。前端可以用已有聚合值替换数值，但不能生成超出 payload 的统计或因果结论。

每条 insight 至少带：`insight_id`、`chart_id`、`release_id`、`slice_id`、`evidence_cells`、`comparison_basis`、`template_id`、`limitations`、`status`。外部注释另带 source URL、event date、checked date 和 review status。

可选 LLM 只润色经过验证的结构化观察，不拥有编造数字、来源、显著性或责任判断的权限。生成结果要能回指实际 cell，筛选变化后旧 insight 必须失效。没有证据时不用固定文案补空。

### 13.3 可复用解释模板

| 观察类型 | 文案结构 | 限制 |
|---|---|---|
| 规模与比例 | “A 的关联数为 nA，高于 B 的 nB；但同口径分母分别为 NA、NB，对应每万篇为 rA、rB。” | 不称为诚信或固有风险差异 |
| 时间趋势 | “在完整年度 y1–y2，数量从 n1 变为 n2；相对变化 g%，绝对变化 d 篇。” | 基期 0/小基数/未完整年时取消增长结论 |
| 时滞 | “有效日期样本 n 篇，中位数 m 年，中间 50% 落在 q1–q3 年。” | 不是全体论文的生存概率 |
| 原因构成 | “Field F 的 N 篇匹配原论文中，n 篇记录 Reason R，占 p%；另有 u 篇原因不可用。” | 多标签、匹配与缺失限制 |
| 集中程度 | “前 k 个实体覆盖 U 篇不同原论文，占 P%；其关联份额为 S%。” | 必须区分 union 与 association |
| 引用持续 | “时序可判定的 E 条观测引用边中，A 条在撤稿后；另有 M 条模糊、U 条日期未知。” | 不推断引用态度 |
| 口径敏感性 | “切换计数口径后，某项从 a 到 b；变动来自多重归属权重，而非新增论文。” | 同时显示计数单位变化 |

比例差写清“百分点”还是“相对百分比”。两个小数的比值不能自动称为“风险增加几倍”。排名差异若来自更换 eligible set，不能写成同一总体的名次变化。

### 13.4 方法演示用合成示例，不得作为研究结论

**规模与比例示例：** 假设相同队列/作品类型下，机构 A 为 80/80,000，机构 B 为 40/8,000。A 的关联数更多，但每万篇分别是 10 与 50。页面应解释“总量更多与比例更高不是一回事”，而不是“B 的研究更不诚信”。这只是算术演示，未控制其他构成因素。

**国家计数示例：** 两篇论文分别关联 CN+US、CN。CN 关联 2 篇，US 关联 1 篇；以两篇唯一论文为分母，覆盖比例为 100% 和 50%；以三次国家–论文关联为分母，关联份额为 2/3 和 1/3；分数计数为 1.5 和 0.5 篇等价值。三种结果都可以正确，但不能叫同一个“占比”。

**作者重叠示例：** 两名作者共同署名同一篇撤稿论文。各有一次关联，关联数合计为 2，但论文只有 1 篇。前一名作者的关联份额为 50%，唯一论文覆盖却为 100%。

合成示例必须显著标注“方法示例，非研究结果”，不能进入 overview 数字、insights 或默认导出。

## 14. 筛选与联动契约

### 14.1 总体决定可用维度

| 当前总体 | 发表年 | 撤稿年 | OA 学科/标准化实体 | RW 原因 | 分母支持的比例 |
|---|---|---|---|---|---|
| RW B | 有日期时 | 有日期时 | 不自动提供 | 可用 | RW 单独不可用 |
| OA A1 | 可用 | 不可由 flag 推导 | 可用但看覆盖 | 不自动提供 | 需要 D |
| 联合 C | 保留各来源日期 | 有效 RW 日期时 | 匹配子集可用 | 可用 | 必须明确 C_D/D 定义 |
| OA A0 诊断 | 可用 | 不可推导 | 仅诊断用途 | 不自动提供 | 不称为原论文撤稿率 |

快照日期是固定来源信息，不提供一个能伪造历史快照的任意日期滑块。发表年筛选与撤稿年筛选使用不同控件，不能只写“年份”。在比例模式中，分母跟随发表队列，不跟随撤稿年过滤。

第一版核心控件为：报告版本、数据总体、corpus（适用时）、作品类型、发表年代、日期模式、学科层级、统计指标、计数规则。国家、机构、期刊等明细筛选只在相应图/切片支持时出现。

国家计数、原因 prevalence、时滞分位数不是一个通用全局 fractional 开关。每张图在 registry 声明自己的 counting applicability；不适用的切换明确禁用并解释。

### 14.2 静态站点不提供无限维度交叉

所有可筛选组合必须有离线生成的 aggregate slice 支撑。第一版发布经过选择的一维分布、二维热力表及有限比较切片，不发布多维笛卡尔积。

`supported_slices` 指明允许的 population/corpus/type/date/taxonomy/country 组合。用户选择未预计算组合时，显示“该组合未预计算”，不得显示“没有撤稿”或由不相容的边际总量拼接比例。

不能通过相加分组中位数、Top-N、distinct counts 或独立边际表得到新切片。作者/国家去重并集需要离线计算。不能为了支持任意过滤而把全部论文、作者或引用边发送到浏览器。

### 14.3 联动一致性

所有被筛选影响的图显示同一 applied-scope 条。全库固定卡片必须标“全库快照，不跟随本图筛选”；不要让相邻组件悄悄采用不同范围。

筛选后同步更新图、标题、单位、观察句、数据表、限制和导出。保留可分享 URL，解析无效参数时提示被拒绝的参数，不静默套用到别的总体。比较最多四组；默认固定同一队列、作品类型和日期口径。

    "publication_year_range": null,

Ready 行至少包含 stable group ID、label、numerator、denominator、value、unit、valid n、missingness/eligibility flags。分布图使用明确的 bin edges、quantiles、ECDF 点或日期区间；不能只传四舍五入后的展示字符串。

### 15.3 体积和性能约束

维持 **全部公开聚合 JSON + 展示样本合计 ≤2 MiB**，包括 v2 与 v3 并存；全站最多 36 条样本，不是每页 36 条。建议 manifest ≤32 KiB、默认概览所需数据 ≤256 KiB，按章节懒加载。地图边界、额外结构数据也必须计入资产预算，不能绕过检查。

超过预算时先减少低价值切片、Top-N 输出或重复字段，不放开原始数据下载，不假装浏览器可查询全库。确需提高预算必须单独评审，不能在实现时默默删除限制。

导出的 CSV 由当前聚合单元生成，带总体、过滤条件、方法版本和日期；保留公式注入防护。导出按钮不意味着站点发布原始 CSV 文件。JSON 缺失值不经格式化函数变成 0。

## 17. 视觉、可访问性与错误状态

使用克制的研究报告风格：清晰层级、充分留白、数字对齐；标题不要重复 emoji。来源颜色可固定区分 RW/OA/联合，但颜色表示来源，不表示真假或严重程度。

连续热力图使用顺序色阶；只有围绕明确参考值的偏差图使用发散色阶。禁止 3D、装饰性雷达图、无解释双轴和按单图随意改变语义的配色。多标签覆盖不使用暗示 100% 分割的饼图。共现优先矩阵/UpSet，而不是难以量化的弦图或毛线网络。

所有交互可用键盘操作，焦点可见，图表有读屏说明与对应数据表；不能只靠颜色区分数据状态。Reduced-motion 模式关闭动画。窄屏保持轴标题、图例和关键限制不重叠；必要时横向滚动明细表而不是压缩文字。

| 状态 | 展示要求 |
|---|---|
| `awaiting_snapshot` | 等待完整快照通过校验；不画伪造的灰色趋势 |
| `not_computed` | 数据阶段尚未执行；不能显示 0 |
| `unsupported_slice` | 此筛选组合未预计算；保留当前选择说明 |
| `missing_denominator` | 可展示数量，不启用比例与相应解读 |
| `insufficient_followup` | 说明观察窗未满足，不与成熟队列直接比较 |
| `small_base` | 数值及 n/N 可检查，取消过度精确排名/增长标题 |
| `missing_data` | 显示缺失范围及分母，而不是自动补零 |
| `zero_observed` | 只有完成扫描且分母有效时才显示观测零 |
| `error` | 读取/验证错误；不混用旧 chunk 和新 manifest |
| `ready` | 完整展示图、解读、证据与限制 |

## 18. 分阶段实现与验收

### S0：当前交付

分析 spec 复核、website report 设计、文档互链。没有执行全量统计，没有新图表或部署成果声明。

### S1：解释性描述报告

完成 snapshot/role/identity/source gates 后，优先 T1、T2、T4、F1、F2 数量模式、R1、R3、E1、E2、Q1–Q3；概览复用其中已验证的观察。无 OA 分母时禁用比例；无匹配时保留相应 unavailable 状态。

### S2：联合分析与分母

增加 T3、F3、F4、R2、R4、G1–G3、E3、E4、P1–P3 的符合条件模式。先支持有限且有解释价值的组合，不承诺任意多维查询。缺少来源/国家/日期质量的模块可以独立禁用，但原因必须可见。

### S3：引用与扩展

完成 incoming citation pipeline 后启用 C1–C4 的相应能力；C1 若只有静态引用计数可独立提前启用。地图、Concept 历史附录、网络与调整模型为后续可选项，不阻塞可正确发布的核心章节。

### 数值与语义验收

- 每个 ready 主图都有与当前 slice 一致的数值观察、比较依据、解释边界和表格。
- 所有比例可由导出中的 n/N 复算；count、paper coverage、association share、fractional 和 cohort proportion 不共用模糊单位。
- 数据状态改变或过滤切换后，旧观察不会残留；未知、未计算、小基数和有效零可被自动测试区分。
- Top-N 图、集中度和 unique-paper coverage 使用各自正确分母；Other 不掩盖 Unknown，排行不含缺失占位实体。
- 日期年轴、部分年度、相同日引用、随访不足、OA flag 与 RW event 的差异都有测试样例。
- 原因共现及 any-topic 模式不被可加总图误呈现。
- C2–C4 必须有 incoming-edge 来源和 eligible targets；没有扫描不能宣称零引用。

### 交互与视觉验收

- 支持桌面、平板、手机代表性视口，轴标题/长名称/图例不重叠；键盘和 reduced-motion 可用。
- 鼠标/键盘选中、URL 分享、重置和 unsupported slice 的结果一致。
- 快速切换总体或章节不出现旧数据配新标题；人口总体、分母和计数方式在截图中也可辨认。
- 关键解释不用打开 tooltip 才能看见；数据表和导出与图上数值一致。
- 概览发现可定位到对应 chart ID 和 cell；任何合成示例都有显著标签且不进入报告统计。

### 发布验收

- schema v2 和 v3 分别验证；新增路径需精确 allowlist，不删除原始数据防护。
- 公开数据总预算和全站样本数量满足约束；无 CSV/Parquet/JSONL/Gzip 原始分片或全量论文/引用边。
- 构建不需要下载快照；数据刷新失败保留最后通过验证的 release。
- 只有实现并通过门槛的章节显示为 ready；不能因为文档列出了 29 张图就声明全部已交付。

## 19. 实现时的决策优先级

当视觉效果与统计含义冲突时，优先保证统计含义；当交互自由度与静态发布预算冲突时，优先保证已发布切片正确；当故事吸引力与证据冲突时，优先保留不确定性。

这个网站的价值不是让读者记住一串排名，而是帮助其分清：**数量与比例、发表与撤稿、关联与责任、观察与解释、数据覆盖与现实总体。**

字段事实与数据来源依据见 [分析 spec 的官方参考资料](OPENALEX_SNAPSHOT_ANALYSIS_SPEC.md#19-official-references-and-review-context)。其余视觉、交互、体积及解释要求是本项目的设计决策，不冒充已验证的研究发现。
