# 快照联合报告：阅读版方法补充

本次针对零上下文读者重写导读，不改变既有 RW-only 报告或快照接受政策。

## 研究范围与筛选

Work 是 OpenAlex 的文献记录，不等于原始研究论文。主体库由 `is_xpac=false` 定义，不是质量认证。默认 article 筛选是为了保持撤稿论文与全部发表论文比较基数的文献形态一致；review 另有比例视图。journal 是发表来源类型，与 Work 的 article 类型可以同时成立。

概览新增筛选表，以全部主体库撤稿标记记录为分母，按文献类型、通知身份、日期的既定顺序产生互斥分组。文献类型交叉表直接读取这批记录的主来源类型，包括未进入默认研究范围的记录；不是只用已保留论文估计期刊覆盖。排除不是删除源数据，也不宣称所有被排除记录无研究价值。

## Concepts 独立分析

```bash
python -m pipeline.snapshot_concepts "$RUN_DIR" --workers 6 --threads 8 --memory-limit 24GB
python -m pipeline.snapshot_report "$RUN_DIR"
python -m pipeline.publish_snapshot "$RUN_DIR/report"
```

新增扫描读取固定清单中的全部 2,446 个 Work 分片，只将已有身份筛选候选的 Concepts 保存在外置运行目录。源大小/修改时间、清单哈希、分片输出哈希和代码版本共同约束续跑；不会重新推断标签。

分别统计筛选后的标记论文和匹配后的 RW 研究论文，第 0、1 级按概念 ID 在每篇内去重。保留快照附带的标签，包括零分祖先标签，不新增阈值或推断祖先。聚合表保留各层前 30 个概念，基数仍是该范围全部论文。覆盖率按发表时期列出有任一第 0–5 级有效标签的论文比例；另列每层缺失。Concepts 是冻结旧体系，不与 Topics 拼接，不提供未经限定的当前学科趋势或风险解释。

本次扫描使用 6 个并发连接，每连接 8 线程、24 GB 内存上限，846 秒完成；这不是内存预分配承诺。原有分母与引用结果复用，避免重复全库扫描。

实际结果：标记研究论文 50,331 篇中，第 0 级有标签 50,325 篇，第 1 级 50,120 篇；匹配 RW 研究论文 43,094 篇中，分别为 43,093 和 42,933 篇。两种范围均涉及 19 个第 0 级概念、284 个第 1 级概念。覆盖较高也不意味着旧体系已恢复更新。

## 国家与作者

国家默认由论文署名机构所在国推得，同一论文内去重；署名地址国家是另一独立口径。不使用作者当前任职机构或推断国籍。关联计数、论文覆盖比例、关联份额、已知成员分数权重分别解释。单一已知国家且署名不完整，不被自动判为完整国内合作。

按本次明确需求增加作者 Top 20 聚合表：按 OpenAlex 作者 ID 的不同关联论文数排序，平局按 ID；姓名取本研究论文署名中该 ID 最常出现的非空名称。保留姓名缺失提示，不凭同名合并，不发布论文清单。共同署名会计入多个作者，排名不是责任认定。完整的作者重复关联分布和集中度仍保留。

## 阅读和发布边界

每章先解释问题与方法，一次显示一个分析；目录、下拉框、上一项/下一项、深链接和浏览器历史使用同一个切片状态。小屏用章节导航和下拉选择，不再堆叠全部图表。技术标识及完整聚合数据仍可展开核对。

论文、记录、作者和引用条数使用整数；比例、年份间隔及分数计数保留必要小数。公开数据仍是原有精确资产白名单，v2+v3 合计不超过 2 MiB，展示样本不超过 36 条。未保存的下载前证据仍明确披露，不因阅读版更新而消失。

验证覆盖 48 项 Python 测试、12 项 Node 测试，以及浏览器逐一选择全部 109 个分析视图。9 章默认页面通过 WCAG A/AA 自动检查和 390/768/1440 像素宽度溢出检查；新增作者表、手机 Concepts、浏览器后退、引用 CSV 和损坏分片拒绝加载也经过验证。自动检查不替代人工可访问性审查。

## 数据集筛选与图表交互补充

`report-source-v1` 是展示层的口径分类，不生成新的统计总体：

| 分类 | 所需选择 | 定义 |
| --- | --- | --- |
| RW | RW | B 原论文总体及仅使用 RW 字段的时间、原因、月度分析 |
| OpenAlex | OpenAlex | A0、A1、D 及其同口径比例；保留标记和通知筛选对 RW 的来源依赖说明 |
| 匹配子集 | RW + OpenAlex | C、C_D 及其比例；匹配 RW 原论文后使用 OpenAlex 元数据，不要求 OA 同时带撤稿标记 |
| 跨库核对 | RW + OpenAlex | 总体核算、Q1/Q2 匹配及字段核对；即使输入总体叫 B，也不能标为 RW 独立分析 |

多选只是开放所需来源齐备的分析，并不对图表数值求和。去重并集没有在本版发布；它不同于匹配子集，需另行定义身份去重、范围及未匹配记录的字段覆盖。Concepts 字段始终来自 OpenAlex：单选 RW 不展示；单选 OpenAlex 显示 A1 分类；多选可额外查看 C 匹配子集分类。

URL 使用 `sources=rw`、`sources=oa` 或 `sources=rw,oa`，与 `slice` 一同保留。改变数据集重置当前切片，章节导航和浏览器历史保留来源；不支持的切片或无可用分析有明确空状态，不偷换另一数据集。旧的无 `sources` 链接按两来源解释。未知来源参数拒绝隐式回退。CSV 记录具体图表的来源分类与定义，而不把页面多选状态当作合并后的样本。

交互点线图沿用现有聚合数值，添加网格刻度、悬停追踪、逐点详情、点击/轻触锁定、方向键导航、Enter/Esc 操作和范围滑块。缩放只限制展示，不重算分母，不缩小 CSV；空心点、未完整时期、排名门槛、阈值线、撤稿事件边界和分位数解释仍保留。缺失年份不补成零或连成完整年度序列。尊重系统减少动态效果设置；点线图随容器宽度适配，长标签的区间图可横向查看，详情面板保持可读。

此次验证为 48 项 Python、17 项 Node 测试；浏览器遍历 109 个分析，其中 31 个交互图逐一验证键盘锁定与取消。另验悬停、固定选中、滑块缩放/重置、来源切换空状态、带来源参数的历史与重载、CSV 来源字段、三种视口宽度、触屏锁定/取消及减少动态效果。9 章默认页面和手机散点图通过自动 WCAG A/AA 检查。全部既有公开统计资产保持不变。
